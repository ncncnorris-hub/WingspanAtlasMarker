# Wingspan Atlas Marker

**[简体中文](README.md) | English**

> 🌐 This English README was **auto-translated from the Chinese original by AI**.
> If anything reads oddly, the [Chinese version](README.md) is authoritative.

A BepInEx MOD for [Wingspan](https://store.steampowered.com/app/1054490/Wingspan/):
during a match it detects **birds in your hand / tray that you have never played before** and
highlights them in the BepInEx console — handy for chasing achievements like "play every bird".
> Detection is strictly read-only: it only reads the "already-played birds" list from your save.
> It **does not modify the game, write to saves, or touch achievements**, and leaves no trace after uninstall.

<img width="795" height="348" alt="image" src="https://github.com/user-attachments/assets/49eaddf0-8afa-458d-9596-f3dc96572e83" />

It is very simple to use:
> After installing the MOD, just play normally (recommended: a 5-player game where you control everyone).
> During play, the console window highlights which birds you have never played
> (along with score, egg limit, wingspan, etc. for cross-checking).
> When you see the hint, grab that bird and play it as usual.

## Features

- Finds, in real time, the birds you have never played that are in your hand (`HAND`) or the deck's face-up tray (`TRAY`).
- One bird per line, with rotating highlight colors, plus basic stats:
  ```
  UNPLAYED (2)
  Common Swift(252) [TRAY] {VP:5 Eggs:2 WS:55 Nest:None Hab:F/G/W}
  Common Buzzard(244) [HAND] {VP:4 Eggs:3 WS:127 Nest:Platform Hab:G}
  ```
  - `VP` victory points · `Eggs` egg limit · `WS` wingspan (cm) · `Nest` nest type · `Hab` habitat (F=Forest / G=Grassland / W=Wetland)
- Console logs are filtered by level so only important messages remain (keeping it clean); the game's `[Operations]` logs are relayed back so they still show.

## Requirements

- Steam version of Wingspan (Unity **IL2CPP**, **x86 / 32-bit**)
- Loader: **BepInEx 6.0.0-be.755** (Unity.IL2CPP, win-x86)

## Installation (players)

This MOD **does not bundle BepInEx** (to avoid redistributing third-party / Unity copyrighted files),
so you install BepInEx first, then drop in the plugin DLL.

1. **Install BepInEx 6.0.0-be.755** (must be the IL2CPP / win-x86 build): download
   `BepInEx-Unity.IL2CPP-win-x86-*.zip` from [BepInEx Releases](https://github.com/BepInEx/BepInEx/releases),
   extract it into the game root (`...\steamapps\common\Wingspan\`), launch once from Steam to let it
   initialize (**the first launch is slow** while it generates interop), then quit.
2. **Add the plugin**: download `WingspanAtlasMarker-vX.Y.Z-插件包.zip` from [Releases](../../releases) and
   put `WingspanAtlasMarker.dll` at
   `<game root>\BepInEx\plugins\WingspanAtlasMarker\WingspanAtlasMarker.dll`
   (or just use [`prebuilt/WingspanAtlasMarker.dll`](prebuilt/WingspanAtlasMarker.dll) from this repo).
3. *(Optional)* Keep the console showing only important info: edit `BepInEx\config\BepInEx.cfg` and set
   `LogLevels = Fatal, Error, Warning` in the `[Logging.Console]` section.
4. Launch the game; the `UNPLAYED` hint appears in the black BepInEx console once a match starts.

See [`docs/运行MOD说明.txt`](docs/运行MOD说明.txt) for detailed steps (Chinese).

## Uninstall

To return to vanilla after you're done: fully quit the game → double-click `卸载.bat` in the game root
(included in the package) → press `Y` to confirm.
Or manually delete `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `dotnet\`, `BepInEx\` from the game root.

## Building from source

Requires .NET SDK 6.0+, and BepInEx installed and run once (so interop references exist).
Then edit `<GameDir>` in `WingspanAtlasMarker.csproj` to your Wingspan path and run:

```
dotnet build
```

The output auto-deploys to `<GameDir>\BepInEx\plugins\`. See [`docs/开发MOD说明.txt`](docs/开发MOD说明.txt) for full details (Chinese).

## Important notes

- **Same game version is safest**: the plugin is compiled against the current game version; a large version
  difference may break it or cause errors.
- This repo contains **no game/Unity copyrighted files** (e.g. `GameAssembly.dll`, `global-metadata.dat`,
  interop assemblies). The interface assemblies needed to build are generated by BepInEx on your machine's first run.
